# ZEOX1ONE — starter GitHub Pages

Site vitrine éditorial statique en HTML, CSS et JavaScript, avec bascule FR/EN.

## Publier avec GitHub uniquement

1. Crée un nouveau dépôt GitHub, par exemple `zeox1one-media`.
2. Décompresse l'archive sur ton ordinateur.
3. Envoie tous les fichiers et dossiers à la racine du dépôt (`index.html`, `styles.css`, `script.js`, `articles/`, `assets/`).
4. Dans le dépôt : **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**.
6. Sélectionne `main` et `/ (root)`, puis **Save**.
7. Attends la fin du déploiement. GitHub affichera l'adresse de ton site dans Settings → Pages.

## Personnaliser

- Recherche/remplace `ZEOX1ONE` dans `index.html`, les pages d'articles et `mentions-legales.html`.
- Modifie les couleurs au début de `styles.css` dans `:root`.
- Les textes FR/EN sont dans `script.js`.
- Les cartes de la page d'accueil pointent vers les exemples dans `articles/`.
- Remplace les articles de démonstration par tes propres contenus vérifiés.

## Important avant publication

- Le nom ZEOX1ONE est provisoire : vérifie la disponibilité du nom et des marques avant de l'adopter.
- Remplace les coordonnées fictives et complète les mentions légales.
- La newsletter est une maquette : aucun formulaire ne collecte d'adresses e-mail.
- N'ajoute pas de liens affiliés sans vérifier les conditions des programmes et le cadre légal adapté à ta situation.
- GitHub Pages héberge des sites statiques : pas de base de données ni de traitement serveur intégré.
